# RTL Modules

This directory contains the Register Transfer Level (RTL) implementation of the 32-bit Single-Cycle RISC-V (RV32I) Processor.

## Modules

- Arithmetic Logic Unit (ALU)
- Control Unit
- Register File
- Program Counter
- Instruction Memory
- Data Memory
- Immediate Generator
- Multiplexers
- Top Module

## Language

Verilog HDL

## Notes

Each module is organized into a separate folder to improve readability and maintainability.
