# Testbench

## Overview

This directory contains the verification environment for the RV32I Single-Cycle Processor.

## Purpose

The testbench is used to:

- Generate clock and reset signals
- Apply test instructions
- Verify arithmetic and logical operations
- Verify memory operations
- Verify branch instructions
- Observe processor outputs during simulation

## Simulation Tool

- ModelSim / QuestaSim
